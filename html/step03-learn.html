STEP 03

  1. 01
    OPTIONS

    There’s usually more than one action that could move you closer. Each one has to pass the proof test.

  2. 02
    IMPACT

    The move that matters most is the one that takes you furthest, not the easiest one. It’s often the one you’ve been avoiding.

  3. 03
    START

    If the move is too big for today, don’t swap it for an easier one. Cut it down to the first part you can do today.

Doing more isn’t progress. Doing what matters is.

EXAMPLE

  1. 01

    OPTIONS

    Phone outside the bedroom by 10pm. No coffee after 2pm. Get up at the same time every day, weekends included.

  2. 02

    IMPACT

    Getting up at the same time every day. It’s the one I’ve been avoiding, because I love a weekend lie-in.

  3. 03

    START

    Set a 6:30am alarm for every day this week, weekends included.

  4. MY PROMISE

    Today, I will set a 6:30am alarm for every day this week, weekends included.
